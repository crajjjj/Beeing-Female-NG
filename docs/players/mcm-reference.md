# MCM Reference

Beeing Female's settings are organized across ten MCM pages.

| Page | What You Configure |
|------|--------------------|
| Settings | Core toggles, message mode, hotkeys |
| Cycle | Phase durations, PMS chance |
| Pregnancy | Trimester durations, belly/breast scaling, miscarriage |
| Impregnate | Conception chances, sperm settings, lore-friendly, NPC impregnation |
| Male | Virility recovery, creature sperm |
| Children | Baby spawn mode, growth settings, SlaveTats tattoos |
| AddOn | Enable/disable loaded addons |
| Info | View current state, sperm donors, pregnancy status |
| Cheat | Force state changes, debug tools |
| System | Mod reset, profile save/load |

For details on the settings behind each page, see:

- [Cycle, Sex & Conception](cycle-and-conception.md) — Cycle, Impregnate, and Male pages
- [Pregnancy & Birth](pregnancy-and-birth.md) — Pregnancy page
- [Children](children.md#mcm-settings-children-page) — Children page
- [NPC Pregnancy & Couples](npc-pregnancy.md#mcm-settings-impregnate-page) — the NPC side of the Impregnate page
- [Tattoos (SlaveTats)](tattoos.md) — the tattoo toggles on the Children page
