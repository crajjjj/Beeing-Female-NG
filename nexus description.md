[center][size=5][b]🌸 Beeing Female NG 🌸[/b][/size]
[size=3]🩸 Menstruation & 🤰 Pregnancy Simulation[/size][/center]

[b]Beeing Female NG[/b] is a next-generation life-simulation mod featuring menstrual cycles, pregnancy, childbirth, and post-birth systems — designed for both players and NPCs.

It also includes a flexible follower system (unlimited followers), new items, and a wide range of configurable gameplay mechanics.

This project is a modern replacement for the original
[b][url=https://www.nexusmods.com/skyrimspecialedition/mods/16546]Beeing Female[/url][/b] mod, rebuilt as an [b]⚙️ SKSE plugin[/b] using [b]CommonLibSSE-NG[/b].

[b]🎮 Supported versions:[/b] Skyrim SE • AE • VR



[size=4][b]❓ TL;DR — Why Beeing Female?[/b][/size]

Beeing Female is built around a [b]🧩 modular add-on framework[/b] and a broad life-simulation feature set rather than a single monolithic overhaul.
